mend is a dependency-free Node patch tool that applies patches in four formats — unified diff, SEARCH/REPLACE blocks, V4A and JSON edits — matching each edit at the first of three tiers (exact, anchored, fuzzy re-indent) and writing every change or none. On the kit's 100 public practice checks it passes 100/100.

## Run it

```sh
node main.ts [options] [PATCH]
```
